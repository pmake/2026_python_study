# 機器學習筆記
## 說明
### .ipynb 檔案
- .ipynb檔案全名interactive python notebook
    - 執行前先點右上角"Select Kernel"選擇執行環境
    - 內容有兩種類別, Code, Markdown 顯而易見的一個是程式碼，一個用來寫說明
        - Outline 功能(預設在介面上方有Outline標籤可點擊)會根據Markdown的標題產生目錄，且可以依據標題快速跳轉到特定單元
- 何時使用.ipynb? => 交互式計算
    - 分步驟探索
        - 例如拿到一堆資料，不知資料結構，想視覺化呈現檢視，一步一步來比較直觀，適合邊做邊看
    - 數據分析
    - 快速原型開發
    - 成果展示
- 何時使用.py? => 專案化開發
    - 建立可重複執行的程式
    - 模組化程式碼
    - 多人協作
    - 正式上線程式
- .ipynb cell的執行順序與關聯性
    - 共享同一個執行環境(Python Kernel)
        - 所有程式碼都建立在同一個執行環境，每個cell點擊前只是一個樣板，點擊執行後才會在環境中執行，並且儲存結果
        - 因此cell擺放的順序不重要，重要的是點擊的執行的順序，想像成一個每次點擊一個cell就是把程式碼放到共用.py檔案最下方接著執行
            - 同一個cell可以任意次數重複執行，每次執行都會更新執行環境中的變數與結果
    - 執行順序的標記：In [ ]（Execution Count）
        - 每個程式碼區塊左側的方括號就是執行順序的計數器：
        - In [ ]：尚未執行。
        - In [*]：目前正在執行中（或正在等待排隊）。
        - In [1], In [2], In [3]...：代表實際被執行的時間先後順序。
    - 常見的「隱藏狀態陷阱」（Hidden State）
        - 因為區塊可以任意順序重複執行，這也是初學者最常遇到 Bug 的地方：
            - 區塊 1
            x = 10
            - 區塊 2
            x = 20
            - 區塊 3
            print(x)
        - 如果依序執行 1 → 2 → 3，會印出 20
        - 如果接著修改區塊 1 並重新執行 1 → 再執行 3（執行順序變成 1 → 2 → 3 → 1 → 3），印出的會是 10
        - 如果把區塊 2 刪除，但沒有重啟 Kernel，記憶體中的變數依然存在，程式依然能跑，但換到別人的電腦上重新從頭跑就會報錯
    - 最佳實踐建議
        - 為了確保整份 .ipynb 邏輯的一致性與可重現性：
            - 由上至下依序排列邏輯：讓程式碼由上到下讀取時具有邏輯連貫性（載入套件 → 資料載入 → 資料處理 → 模型訓練）。
            - 驗證方式：在完成筆記本或分享給他人之前，建議點擊選單的 Restart Kernel -> Run All Cells 重啟核心然後執行全部，確保整份檔案從乾淨狀態由上往下跑完全部區塊時不會出錯。
- 小知識
    - 每個cell的最後一行會自動輸出，不用自己打print
    
## 主要任務類別
- 預測任務(Predictive Modeling)
    - 回歸任務(Regression)
        - 預測連續值，例如：用房市資料預測房價、氣象資料預測氣溫
    - 分類任務(Classification)
        - 預測類別，例如：垃圾郵件分類、汽車是否需要進行保養
- 關聯任務(Association Rule Mining)
    - 找出資料中的關聯規則，例如：顧客購買習慣分析，啤酒與尿布
- 聚類任務(Clustering)
    - 將資料分群，例如：顧客分群

## 資料預處理
- 缺失值: 刪除, 填補(平均數, 中位數, 眾數), 建立模型預測補值
    - 缺失值量少且隨機分布 -> 刪除
    - 缺失值量大且隨機分布 -> 填補(平均數, 中位數, 眾數)
    - 缺失值分布不隨機 -> 建立模型預測補值
    - KNN 
        - 何為KNN? => K-Nearest Neighbors，k是距離最近的k筆資料
            - 核心概念: 預測一個未知點的值，會去找離它最近的k筆已知資料，然後取這些已知資料的值的平均作為預測值
        - 用sklearn處理範例:
            - from sklearn.impute import KNNImputer
            - knn_imputer = KNNImputer(n_neighbors=2)
            - knn_imputer.fit_transform(df)
            - n_neighbors 指定要取最相似的幾筆樣本做平均
    - Iterative Imputer
        - 何謂Iterative Imputer? => IterativeImputer也是一種補植的方法, 它會對每一筆缺失值建立一個模型, 然後預測缺失值
            - 用迴歸模型來預測缺失值, 會對每一筆缺失值建立一個模型, 然後預測缺失值
- 標準化 Standardization (或 Z-score Normalization)
    - 何謂標準化? => (x - mean) / std
    - 為何需要標準化? => 防止數值過大或過小影響模型結果
    - 進行標準化後，樣本數不變，但數值會在平均數為0，標準差為1的分布區間
- 正規化 Min-Max Normalization
    - 何謂正規化? => (x - min) / (max - min)
    - 為何需要正規化? => 防止數值過大或過小影響模型結果
    - 進行正規化後，樣本數不變，將數值等比例縮放到 $[0, 1]$ 或 $[-1, 1]$ 區間。
- Normalizer
    - 何謂Normalizer? => Normalizer假設一個row(也就是一筆資料)的特徵資料有尺寸關聯性, 將其縮放到單位長度(Unit Norm)
- 對數轉換 Log Transformation
    - 何謂對數轉換? => log(x)
    - 為何需要對數轉換? => 當資料分布嚴重偏斜(skewed)時, 對數轉換可以讓資料分布更接近常態分布
- 適用場景與差異可詢問LLM
### 常用特徵縮放與轉換方法比較 (使用檢視模式即可見正常表格)
| 方法名稱 | 處理方向 (維度) | 轉換性質 | 核心公式 | 是否改變分佈形狀？ | 主要解決問題與適用場景 | 常用工具 / 函式 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **標準化<br>(Standardization)** | 垂直<br>(按欄 / 特徵) | 線性 | $z = \frac{x - \mu}{\sigma}$ | **否**<br>(維持原分佈，中心移至 0，標準差為 1) | 各特徵尺度單位不同；模型假設為常態或零中心（如 PCA、SVM、Logistic Regression）。 | `StandardScaler` |
| **正規化<br>(Min-Max Scaling)** | 垂直<br>(按欄 / 特徵) | 線性 | $x' = \frac{x - x_{min}}{x_{max} - x_{min}}$ | **否**<br>(維持原分佈，數值等比壓縮至 $[0, 1]$) | 需要嚴格固定數值邊界（如影像像素 $0\sim255$、KNN 距離比對）。對離群值敏感。 | `MinMaxScaler` |
| **樣本正規化<br>(Normalizer)** | **水平**<br>**(按列 / 樣本)** | 向量縮放 | $x' = \frac{x}{\|x\|_p}$<br>(通常取 L2 範數) | **單一樣本**<br>轉為長度為 1 的單位向量 | 只在乎特徵間的「相對比例/方向」，而非絕對數值（如 TF-IDF 消除文章長度差異、臉部特徵比對）。 | `Normalizer` |
| **對數轉換<br>(Log Transform)** | 垂直<br>(按欄 / 數值) | **非線性** | $y = \log(x + 1)$ | **是**<br>(將長尾右偏分佈修正為近似常態) | 資料有**長尾效應 / 嚴重右偏**（如房價、年薪、網站瀏覽量），消除極端大值干擾。 | `np.log1p`<br>`FunctionTransformer` |


### 類別型文字資料編碼方法比較
| 比較項目 | **LabelEncoder** (標籤編碼) | **OrdinalEncoder** (有序編碼) | **OneHotEncoder** (獨熱編碼) |
| :--- | :--- | :--- | :--- |
| **核心機制** | 依字典序將類別轉為整數（`0, 1, 2...`） | 依**自訂或預設順序**將類別轉為整數（`0, 1, 2...`） | 每個類別擴展為獨立的二元欄位（`0/1` 矩陣） |
| **主要處理對象** | **目標變數 $y$**（1D 向量） | **輸入特徵 $X$**（2D 矩陣，支援多欄位） | **輸入特徵 $X$**（2D 矩陣，支援多欄位） |
| **維度變化** | **不變**（維持 1 欄） | **不變**（各欄位維持 1 欄） | **增加**（每欄擴展為 $K$ 個新欄位） |
| **順序/大小假定** | **有**（但無法自訂有意義的順序） | **有**（專為**自然有序特徵**設計） | **無**（各類別彼此正交、完全平等） |
| **自訂等級順序** | ❌ 不支援（固定依字元排序） | ✅ **支援**（可傳入 `categories` 指定順序） | ➖ 不適用（無順序概念） |
| **解決的核心問題** | 將字串目標標籤數值化供模型計算 | 將**具層級/等級的文字特徵**合理數值化且不增加維度 | 消除無序特徵的大小偏誤，**保留無序類別的獨立性** |
| **最佳適用場景** | 分類任務的**預測目標（$y$ 標籤）**<br>（如 `['貓', '狗', '鳥']` $\rightarrow$ `[0, 1, 2]`） | **有序特徵（Ordinal Features）**<br>（如 尺寸 `S < M < L`、學歷 `高中 < 大學 < 碩士`） | **無序特徵（Nominal Features）**<br>（如 顏色 `紅/綠/藍`、城市 `台北/台中/高雄`） |
| **適合的模型** | 各類分類模型的輸出端 | **樹狀模型**最佳；若順序間距合理也可配合線性/神經網路 | **所有模型**（特別是線性回歸、SVM、KNN、神經網路等距離敏感模型） |
| **缺點與限制** | 不適合用於特徵 $X$；無法指定順序關係 | 不適合用於無順序特徵；隱含「等間距」假設可能與現實有落差 | 類別過多時會造成**維度災難**（高基數問題）與記憶體暴增 |

> **💡 快速選用口訣**
> - **要轉 $y$（答案標籤）** $\rightarrow$ 使用 **`LabelEncoder`**
> - **要轉 $X$（特徵）且有順序大小** $\rightarrow$ 使用 **`OrdinalEncoder`**
> - **要轉 $X$（特徵）且無順序大小** $\rightarrow$ 使用 **`OneHotEncoder`**

## 訓練過程
- 資料收集
- Split dataset
    - 將原始資料集拆分為訓練集(Training Set)與測試集(Test Set)。
    - 訓練集用於訓練模型參數，測試集用於評估模型泛化能力，避免過度擬合。
    - 切割時需注意設定`random_state`以確保結果可重複。
        - 什麼是random_state?
            - 設定隨機種子的概念，種子相同，隨機抽樣結果就會相同，從同樣的100筆中抽10筆，每次都會抽相同的10筆。
        - 設定 random_state 的好處與壞處
            - 設定 random_state 的好處：你可以確保每次切割出來的訓練集和測試集都是一樣的，這樣你可以重現實驗結果，比較不同模型的表現。
            - 設定 random_state 的壞處：無法評估模型的泛化能力，因為每次切割出來的訓練集和測試集都是一樣的，無法評估模型在不同資料上的表現。
    - 永遠在資料預處理之前切割資料，避免 Data Leakage。
- 資料預處理
    - 將原始資料集進行預處理，包括缺失值處理、特徵縮放、類別型文字資料編碼等。
    - 預處理後的資料集將用於訓練模型。
    - 資料前處理核心原則：
        - 永遠在切分訓練與測試集後進行前處理，或善用 `sklearn.pipeline.Pipeline` 與 `ColumnTransformer` 杜絕 Data Leakage。
        - 避免在 Pandas 3.0+ 中使用 `inplace=True`。
        - 對於無大小順序的類別型資料，優先使用 One-Hot Encoding 而非整數標籤編碼。
- 建立模型
    - 根據問題類型選擇合適的模型，例如分類問題選擇邏輯迴歸，迴歸問題選擇線性迴歸等。
    - 建立模型後，使用訓練集對模型進行訓練。
- 評估模型
    - 使用測試集對模型進行評估，計算模型的準確率、召回率、F1分數等指標。
    - 評估結果將用於模型調優。
- 模型調優
    - 根據評估結果，調整模型參數，以提高模型的準確率、召回率、F1分數等指標。
- 模型部署
    - 將訓練好的模型部署到生產環境中，用於預測新的資料。
