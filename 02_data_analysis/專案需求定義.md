# 專案需求

## 給定條件

- 兩種員工類別。皆為時薪制，時薪皆為190元。
    - "常日班": 
        - 周一到五為正常上班日, 假日上班算加班，適用常日班加班費計算規則。
    - "假日班": 只有假日上班，適用假日班加班費計算規則。
- "常日班"加班費計算規則:
    - 一般工時: 平日工時8小時以內(當日工時<=8)工時為1倍時薪。
    - 平日加班: 
        - 當日工時第9~第10小時為1.34倍時薪
        - 當日工時第11~12小時為1.67倍時薪
        - 當日總工時超過12小時部份不給薪
    - 假日加班:
        - 假日當日第1~2個小時1.34倍時薪
        - 假日當日第3~12個小時1.67倍時薪
        - 假日當日總工時超過12小時部份不給薪
- "假日班"加班費計算規則:
    - "假日班"皆為1倍時薪，無超時倍數。
- 轉場加給定義:
    - 同一個員工(以"保母姓名"做為區別)，同一工作日("排班日期")內在多個"居住地址"工作的情況下，每多一個地址，工時加算15分鐘。
        - 例如a保母同一工作日去了三個地址，則工時加算30分鐘。

## 給定資料
- 小量參考資料.xlsx
- 好寶寶系統設定.xlsx

## 需求輸出欄位(從給定資料中分析取得)
- 基本資料:
    - 姓名, 職稱, 身份證字號, 出生年月日, 員工類別(常日班/假日班)
- 平日工時:
    - 正常工時時數(0~8小時)
    - 平日加班時數(9~10小時)
    - 平日加班時數(11~12小時)
    - 平日轉場加時
- 假日工時:
    - 假日工時(0~2小時)
    - 假日工時(3~12小時)
    - 假日轉場加時
## 欠缺資料(需客戶提供，已先用dummy資料補全)
- 職稱, 身份證字號, 出生年月日, 員工類別(常日班/假日班)
- 假日資訊

# 工作任務
## 主要任務
- 撰寫python程式碼，依給定條件需求從給定資料中分析取得需要的欄位，建立薪資單Excel檔，包含以下工作表。
    - by 員工的每日工時明細表，欄位如下:
        - 日期, 員工類別(常日班/假日班),  正常工時時數(0~8小時), 平日加班時數(9~10小時), 平日加班時數(11~12小時), 平日轉場加時, 假日工時(0~2小時), 假日工時(3~12小時), 假日轉場加時
        - 每位員工會有一個對應的工作表，是by日期的工時統計表
        - 工作表名稱格式: "<個別員工姓名>_<個別身份證字號>"
    - 員工工時統計表，欄位如下:
        - 員工姓名, 職稱, 身份證字號, 出生年月日, 員工類別(常日班/假日班), 正常工時時數(0~8小時), 平日加班時數(9~10小時), 平日加班時數(11~12小時), 平日轉場加時, 假日工時(0~2小時), 假日工時(3~12小時), 假日轉場加時
            - 是每日工時明細表加總後的最終結果，只有一個工作表，每位員工只有一列資料。
    - 驗證用資料表，欄位如下:
        - 員工姓名, 身份證字號, 數據來源, 正常工時時數(0~8小時), 平日加班時數(9~10小時), 平日加班時數(11~12小時), 平日轉場加時, 假日工時(0~2小時), 假日工時(3~12小時), 假日轉場加時
            - 數據來源有兩個:
                1. by 員工的每日工時明細表
                2. 員工工時統計表
            - 後面的各類工時來源依據數據來源定義使用excel內部公式分別統計對應的工作表內容取得做為正確性驗證比對之用
            - 兩個數據來源的各類工時加總後理論上應該完全相同，
    - 異常情況工作表，欄位如下:
        - 異常原因, 員工姓名, 身份證, 異常日期
            - 彙整所有不符常規業務邏輯之紀錄，目前定義包含「假日班於平日出勤」。
