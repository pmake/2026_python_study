# ADR 0006: 轉場工時獨立統計與個人薪資單動態寫入機制

- **狀態**：Accepted (已接受)
- **日期**：2026-07-31

## 背景與問題 (Context)
1. 原工時統計邏輯中，轉場加給時數會加總進「當日總工時」，進而可能將工時推升超過 8 小時而引發平日加班費計算。需求提出將轉場工時完全獨立統計，不影響加班時數。
2. 需要依據 `files/薪資單表單/好寶寶薪資格式.xlsx` 範本，動態複製並產出各員工獨立的個人薪資單檔案（檔名：`<員工姓名>_<身份證字號>.xlsx`），並將計算後的小時數資料寫入對應欄位。

## 決策 (Decision)
1. **轉場工時獨立統計**：
   - 「當日總工時」僅採計實際「服務工時」，用於判定 8 小時正常工時與平日/假日加班分段。
   - 「轉場加時時數」完全獨立累計，平日轉場計入 `正常工時轉場時數`，假日轉場計入 `休假日轉場時數`，完全不推升或影響加班工時。
2. **假日加班工時三段化**：
   - 為對應薪資單範本第 18、19、20 列，假日工時每日細分為：`0~2小時` (前2小時, E18)、`3~8小時` (E19) 與 `9~12小時` (E20)。
3. **個人薪資單動態寫入**：
   - 複製 `files/薪資單表單/好寶寶薪資格式.xlsx` 模版。
   - 將員工基本資訊（姓名: `C5`、職稱: `G5`、身分證字號: `E6`、出生年月日: `J6`）與當月累計工時（以小時為單位寫入 `E8`, `E9`, `E16`~`E21`）填入黃色欄位。
   - 檔案儲存至 `files/產出統計報表/<員工姓名>_<身份證字號>.xlsx`，產出數量與員工總表人數一致。

## 影響與後續 (Consequences)
- **正面影響**：
  - 轉場工時與服務工時徹底解耦，加班費計算更符合實際照顧勞務天數與規範。
  - 實現自動化生成個人化薪資單 Excel 檔案，大幅提升人資作業效率。
