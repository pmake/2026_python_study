# ADR 0001: 假日班平日出勤之薪資計算與異常稽核處理

- **狀態**：Accepted (已接受)
- **日期**：2026-07-30

## 背景與問題 (Context)
在專案需求中，「假日班」員工的定義為僅於假日上班，且適用 1 倍時薪無超時倍數計算。
但在實際業務操作或排班資料中，可能出現假日班員工於平日（周一至周五）出勤的服務紀錄。需要決定：
1. 平日出勤時的薪資計算方式為何？
2. 如何管理與警示此類不符預期排班之情況？

## 決策 (Decision)
1. **薪資計算**：假日班員工不論出勤日為平日或假日，均維持「1 倍時薪、無超時加班倍數」之規則，並同樣受「單日總工時超過 12 小時部分不給薪」之限制。
2. **異常稽核**：在最終輸出的薪資 Excel 檔案中，額外增加一個「異常情況」工作表，將所有「假日班於平日出勤」之紀錄輸出，欄位包含：
   - `異常原因`（固定填入："假日班於平日出勤"）
   - `員工姓名`
   - `身份證`
   - `異常日期`

## 影響與後續 (Consequences)
- **正面影響**：薪資計算邏輯保持簡潔統一，且所有非預期排班紀錄皆被透明化記錄於獨立工作表中，便於人資與主管覆核。
- **負面影響/風險**：若未來新增更多異常類型（例如常日班超時未申報等），需擴充異常判定模組。
