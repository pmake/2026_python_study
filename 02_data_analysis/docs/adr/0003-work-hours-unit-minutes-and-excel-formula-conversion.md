# ADR 0003: 工時單位以分鐘儲存並透過 Excel 公式轉換為小時

- **狀態**：Accepted (已接受)
- **日期**：2026-07-30

## 背景與問題 (Context)
原始服務紀錄與轉場加給之最小精度皆為「分鐘」（例如 55 分鐘、15 分鐘）。
在產出 Excel 薪資明細與統計表時，需要決定內部計算與表格填入的數值單位，以及如何呈現小時數。

## 決策 (Decision)
1. **資料維護**：在 Python 內部資料處理及產出「每日工時明細表」時，基礎工時欄位（正常工時、各階加班工時、轉場加時）皆以 **整數或浮點數「分鐘 (Minutes)」** 為單位進行計算與寫入。
2. **Excel 公式轉小時**：在「員工工時統計表」與「驗證用資料表」等需展示「小時數」的欄位中，使用 Excel 動態公式（例如 `=SUM(...)/60` 或 `=單元格/60`）將分鐘轉換為小時。

## 影響與後續 (Consequences)
- **正面影響**：避免在 Python 階段提早進行浮點數除法導致的精確度損失與除不盡循環小數問題，確保數據精準且公式結構清晰透明。
