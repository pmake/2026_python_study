# ADR 0004: 每日工時明細表採用完整日曆日期補全

- **狀態**：Accepted (已接受)
- **日期**：2026-07-30

## 背景與問題 (Context)
每個員工的「每日工時明細表」工作表需記錄當月每日工時。需決定是否包含無排班/無服務紀錄的日期。

## 決策 (Decision)
1. 個別員工的每日工時明細表（工作表 `<姓名>_<身份證字號>`）將自動產生當月份的所有天數（如 7 月 1 日至 7 月 31 日，共 31 列）。
2. 對於員工未出勤的日期，明細表照常列出該日期，各工時欄位數值補 `0`。

## 影響與後續 (Consequences)
- **正面影響**：固定每個員工明細表的資料列範圍（Row 2 至 Row 32），使「員工工時統計表」與「驗證用資料表」中的 Excel 加總公式（如 `=SUM('徐童真_H900068001'!C2:C32)/60`）擁有固定一致的語法與結構，大幅提高資料比對的穩健度。
