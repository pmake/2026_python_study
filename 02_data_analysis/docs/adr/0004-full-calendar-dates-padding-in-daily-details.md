# ADR 0004: 每日工時明細表採用全動態連續日曆區間補全

- **狀態**：Accepted (已修訂)
- **日期**：2026-07-31

## 背景與問題 (Context)
每個員工的「每日工時明細表」工作表需記錄當期每日工時。來源資料可能包含任意月份或跨月份排班紀錄（如 28 天、30 天、31 天或跨月區間），需決定如何產生時間軸及連動 Excel 加總公式。

## 決策 (Decision)
1. 由來源《服務紀錄總表.xlsx》之 `排班日期` 自動計算最小日期與最大日期，建立全動態連續日曆列表 `all_dates`（總天數 $N$）。
2. 個別員工的每日工時明細表（工作表 `<姓名>_<身份證字號>`）將依據 `all_dates` 動態產生 Row 2 至 Row $1+N$。對於員工未出勤的日期，照常列出該日期，各工時欄位數值補 `0`。
3. 「員工工時統計表」中的加總公式採動態字串產生，範圍精確指向 `=SUM('<Sheet>'!C2:C{1+N})/60`，消除任何硬編碼。

## 影響與後續 (Consequences)
- **正面影響**：完全解除對「7月」與「31天」的硬編碼限制，使分析腳本具備通用處理任何月份或跨月份資料的能力，且 Excel 加總公式範圍永遠與實際日曆天數百分之百精確對應。
