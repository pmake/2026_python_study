# ADR 0005: 缺失與異常格式資料之過濾與稽核紀錄處理

- **狀態**：Accepted (已接受)
- **日期**：2026-07-31

## 背景與問題 (Context)
原始服務紀錄（如 `服務紀錄總表.xlsx`）中，部分欄位（例如 `服務時間長度(分)`）可能包含無效文字（如 "暫無資料"、"N/A"）、空白 null 值或非合法數值。
需要決定：
1. 如何處理這些無效數據以避免計算錯誤？
2. 是否需要追蹤與記錄被排除的紀錄？

## 決策 (Decision)
1. **資料清洗與過濾**：
   - 於 Python 處理階段，對 `服務時間長度(分)` 進行數值強制轉換（`pd.to_numeric(..., errors='coerce')`）。
   - 凡數值為 `NaN`、非數字字串（如 "暫無資料"）、或 $\le 0$ 之紀錄，一律排除，不參與工時分段與轉場計算。
2. **異常稽核輸出**：
   - 將被排除的無效紀錄同步寫入「異常情況工作表」，填寫：
     - `異常原因`：`資料格式異常(非數值工時: "暫無資料")`
     - `員工姓名`
     - `身份證`
     - `異常日期`

## 影響與後續 (Consequences)
- **正面影響**：確保薪資與工時計算不會因髒資料引發 `TypeError` 或失真，且維持 100% 透明度，方便人資追查缺失數據。
